# Spacing
In order to keep the design system consistent and easy to develop with a spacing system is used.
This system is not linear, meaning more options are available for smaller sizes where the difference between two values is more pronounced.

A base value of **2** is used and all other values are calculated from that. For example:
  - **j-space-4** is **2 x 4 = 8px**
  - **j-space-16** is **2 x 16 = 32px**
